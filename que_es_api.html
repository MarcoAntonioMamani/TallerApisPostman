¿Qué es una API?

Una API (Application Programming Interface) es un intermediario que permite que dos sistemas se comuniquen siguiendo reglas acordadas: qué se puede pedir, cómo se pide y qué se recibe de vuelta. Una aplicación no necesita saber cómo está construido el otro sistema por dentro: solo necesita conocer su API.

¿Por qué se usan APIs?

🔒 SeguridadLas apps nunca tocan la base de datos directamente. La API decide qué se puede ver y quién puede verlo.
♻️ ReutilizaciónUna sola API sirve a la web, al móvil y al escritorio. La lógica se escribe una vez.
🧩 IndependenciaEl backend puede cambiar por dentro sin romper las apps, mientras respete el contrato.
🔗 IntegraciónPermite conectar sistemas de distintas empresas, tecnologías y lenguajes.
Idea clave: la API es el mesero. Recibe un pedido (request), lo lleva a la cocina (servidor y base de datos) y trae el plato (response). Solo atiende lo que está en el menú (el contrato o documentación). Probar una API es verificar que el mesero entrega lo correcto, a tiempo, y que responde bien cuando se le pide algo que no existe.
