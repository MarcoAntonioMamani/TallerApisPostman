Descubre las APIs de una página web

Cada vez que usas una página web, por detrás se están llamando APIs. El navegador permite verlas con sus herramientas de desarrollador (DevTools). Practica abajo con la tienda simulada: haz clic en sus botones y observa qué peticiones aparecen.
1Abre el sitioEn Chrome o Edge, entra a la página que quieres analizar.
2Abre DevToolsF12 o Ctrl+Shift+I.
3Pestaña NetworkMuestra todo lo que el navegador pide al servidor.
4Filtro Fetch/XHROculta imágenes y estilos: deja solo las llamadas a APIs.
5Haz una acciónBusca, inicia sesión, agrega al carrito… y mira qué aparece.
6Abre una peticiónClic en la fila: Headers, Payload, Response y Timing.

De DevTools a Postman

Copy as cURL
Abre una petición en el panel de arriba y presiona “Copy as cURL”. El comando aparecerá aquí.
(todavía no copiaste ninguna petición)
Importarlo en Postman
  1. En DevTools, clic derecho sobre la petición → Copy → Copy as cURL (bash).
  2. En Postman, botón Import (o Ctrl+O).
  3. Pega el comando en el cuadro de texto.
  4. Postman crea el request con su método, URL, headers y body.
  5. Presiona Send: es la misma petición que hizo la página.
⚠ Cuidado: un cURL copiado incluye las cookies y tokens de tu sesión. Úsalo solo en ambientes de prueba y nunca lo pegues en chats, tickets ni documentos compartidos.

Qué observar en cada petición

Method + URL¿Qué endpoint llamó la página y con qué método?
Status¿Salió bien (2xx) o hubo un error (4xx/5xx)?
Payload¿Qué datos envió la página en el body o en los query params?
Response¿Qué devolvió el servidor? ¿En qué formato?
Time¿Cuánto tardó? Una API lenta hace lenta toda la página.
Idea clave: la página web es solo la “cara”. Lo que muestra lo obtiene llamando a APIs, y esas llamadas se pueden ver, copiar y repetir. Esta es una de las formas más rápidas de descubrir qué endpoints probar cuando no hay documentación: se observan en DevTools y se llevan a Postman.
