¿Qué es Postman?

Postman es una aplicación para enviar requests a una API y ver sus respuestas sin escribir código. Es como un navegador, pero para APIs: eliges el método, escribes la URL, agregas headers o body, presionas Send y ves el status, el tiempo y el body de la respuesta. Además permite guardar, organizar, automatizar y compartir esas pruebas.

¿Para qué se usa?

🔍 Explorar una APIProbar endpoints a mano para entender qué reciben y qué devuelven.
✅ ProbarEscribir tests que validan status, datos y reglas en cada respuesta.
🗂 OrganizarGuardar requests en colecciones, con variables y ambientes (DEV, QA).
⚙️ AutomatizarEjecutar colecciones completas, con datos de archivos, desde la app o la terminal.

⚠ En equipos de trabajo: Postman guarda las colecciones en la nube de tu cuenta. Antes de usarlo con APIs de la empresa, sigue las políticas internas: qué cuenta usar, qué datos se pueden guardar y dónde. Nunca guardes contraseñas, tokens ni datos reales de clientes en una colección.
💡 También existe Postman en la web (go.postman.co). Para llamar APIs internas o de tu propia máquina necesita el Postman Desktop Agent; por eso en el taller usamos la aplicación de escritorio.
