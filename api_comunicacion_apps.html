¿Cómo se comunican las aplicaciones?

Web, móvil y escritorio no hablan con la base de datos ni con otros sistemas directamente: piden lo que necesitan a una API. La API aplica las reglas de negocio y decide si consulta su base de datos o llama a un servicio externo.
