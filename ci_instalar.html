Instalar y preparar Jenkins

Para el taller instalamos Jenkins en tu propia PC: así controller y agente son la misma máquina. Son cinco pasos, y casi todo se hace una sola vez. Haz clic en cada paso para ver la pantalla correspondiente.
1Instalar Java 21Jenkins está hecho en Java y necesita Java 21 o 25. Descarga el instalador .msi de Eclipse Temurin 21 (LTS) y marca Set JAVA_HOME.
2Descargar Jenkins LTSEn jenkins.io/download elige LTS → Windows. LTS es la versión estable: se actualiza cada 12 semanas.
3Ejecutar el instaladorSe instala como servicio de Windows: arranca solo al prender la PC. En Service Logon elige Run service as LocalSystem (suficiente para practicar). Puerto: 8080 → Test Port.
4Comprobar el servicioSi el servicio está RUNNING, abre http://localhost:8080 en el navegador.
5Alternativa: DockerSi tienes Docker, un solo comando levanta Jenkins sin instalar Java. El contenedor es Linux: el Jenkinsfile del taller funciona igual porque usa sh o bat según el sistema.
Símbolo del sistema (administrador) clic en un paso ▸

  

  
⚠ En un equipo corporativo, instalar Java y un servicio de Windows suele requerir permisos de administrador: solicítalo a soporte con anticipación. En la empresa, Jenkins no se instala en la PC de cada persona: hay un servidor compartido administrado por el equipo de plataforma, y tú solo creas tu job.







  
1Desbloquear JenkinsLa primera vez pide una clave de un solo uso que Jenkins escribió en un archivo de su carpeta. Ábrelo, copia la clave y pégala.

  
2Install suggested pluginsInstala el paquete recomendado: Pipeline, Git, Credentials, JUnit, Timestamper y otros. Tarda unos minutos.

  
3Crear el usuario administradorTu usuario para entrar a Jenkins. Usa una contraseña propia y segura: no la de tu correo ni la de otro sistema.

  
4Jenkins está listoDeja la URL http://localhost:8080/ y presiona Start using Jenkins. Verás el panel principal, todavía vacío.






  
1Administrar Jenkins → PluginsDesde el panel: Manage Jenkins → Plugins. Ahí se instalan, actualizan y desactivan.

  
2Buscar e instalarEn Available plugins busca y marca NodeJS, Allure y Pipeline: Stage View. Presiona Install.

  
3ReiniciarMarca Restart Jenkins when installation is complete. Al volver, revisa en Installed plugins que aparezcan.

  
4Qué hace cada unoLa tabla de la derecha resume los plugins que usa nuestro pipeline.






  
1Manage Jenkins → ToolsAquí se declaran las herramientas que los pipelines pueden pedir por nombre. Jenkins las descarga e instala solo en el agente.

  
2NodeJS: node-ltsAdd NodeJS → Name node-lts → ☑ Install automatically → la versión LTS más reciente. Es lo que pide tools { nodejs 'node-lts' }.

  
3Allure Commandline: allureAdd Allure Commandline → Name allure → ☑ Install automatically → From Maven Central, la versión 2 más reciente. Es lo que usa el paso allure para generar el reporte.

  
4GuardarSave. Los nombres deben coincidir exactamente con los del Jenkinsfile: si no, el build falla con Tool type "nodejs" does not have an install of "node-lts" configured.






  
1Manage Jenkins → CredentialsEntra a System → Global credentials → Add Credentials.

  
2Secret text: la apiKeyKind Secret text, Secret special-key (la clave pública de práctica de Petstore), ID petstore-api-key. El ID es el nombre que usa el Jenkinsfile.

  
3Jenkins la protegeSe guarda cifrada. En el log del build aparece como ****, aunque Newman la imprima.

  
4Repositorio privado (opcional)Si tu repositorio es privado, agrega otra credencial Username with password: tu usuario de GitHub y un Personal Access Token de solo lectura (no tu contraseña).





Lista final: Jenkins abre en localhost:8080, tiene los plugins NodeJS y Allure, las herramientas node-lts y allure, y la credencial petstore-api-key. Con eso, cualquier pipeline del taller puede ejecutarse.
